Macro Nowcasting System

Current-quarter US GDP growth and recession probability, estimated from 29 FRED indicators with a mixed-frequency dynamic factor model. Rebuilt every weekday by GitHub Actions.

How the US economy is doing right now: its growth rate and the odds of a recession, read from 29 fast-moving data sources instead of waiting for the official numbers. Rebuilt automatically every weekday.

Official GDP prints four to eight weeks after a quarter closes. This system reads higher-frequency data (payrolls, jobless claims, the yield curve, credit spreads) to estimate current-quarter conditions in real time, the same class of problem the Atlanta Fed's GDPNow and the Chicago Fed's CFNAI are built to solve. Every historical estimate uses only data that had actually published at that point in time.

Official economic growth numbers (GDP) come out weeks after each quarter ends. This tool reads faster-moving data, like hiring, jobless claims, and interest rates, to estimate how the economy is doing right now instead of waiting. Every historical estimate only uses data that was actually available at that point in time, the same way an investor living through it would have seen it.

      Out-of-sample figures come from a pseudo-real-time replay that rebuilds the nowcast month by month from data vintages, so they are the honest numbers rather than the in-sample ones. Benchmarks are pulled live from FRED on each run.

      These scores come from re-running the tool month by month through history, each time showing it only the data that existed back then, and checking it against what actually happened. The comparisons to well-known Federal Reserve indexes are pulled fresh on every run, so it is held to a real standard rather than graded on its own curve.
